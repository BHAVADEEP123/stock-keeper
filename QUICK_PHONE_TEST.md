## 🎯 THE SIMPLEST PATH (5 MINUTES)

### Click These Buttons In Order:

```
1. Open Android Studio
   ↓
2. File → Open → D:\[L0]WEB\stock-keeper
   ↓
3. WAIT for "Gradle sync finished" (green checkmark)
   ↓
4. Device Manager (right side) → Play ▶ button
   ↓
5. WAIT for Android phone to appear (30-60 seconds)
   ↓
6. Click GREEN RUN BUTTON ▶ at top
   ↓
7. Pick emulator → Click OK
   ↓
8. WAIT for "Build successful" (1-2 minutes)
   ↓
9. APP APPEARS ON YOUR VIRTUAL PHONE! 🎉
```

## ⚠️ IF SOMETHING GOES WRONG

| Problem | Fix |
|---------|-----|
| "Gradle sync failed" | File → Sync Now |
| "Build failed" | Build → Clean → Run again |
| "No device" | Device Manager → Create → Play ▶ |
| "Very slow" | Normal! Wait 1-2 min (first time) |
| "App crashed" | Check Logcat (View → Tool Windows) |
